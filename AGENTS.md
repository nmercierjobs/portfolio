# Project Architecture

- Keep detailed engineering proofs in dedicated routed pages linked from the relevant project approach, so the main case study remains scannable while technical depth stays accessible.
- Image captions use the shared `.figure-caption` class in `src/index.css` so caption size and color are tuned in one place instead of per-page Tailwind utilities.
- Project page body text uses the shared `.project-body` class in `src/index.css` so its font size is tuned in one place instead of per-page Tailwind utilities.
- Pages whose centered text should share the résumé's axis use the `.resume-axis` class, and the résumé's horizontal nudge comes from the `--content-center-offset-x` token in `src/index.css`, so both pages stay aligned from one value instead of duplicated offsets.
- The sidebar's width and the main content's left offset are one value written twice — the `w-[...]` in `src/components/layout/Sidebar.tsx` and the matching `lg:ml-[...]` in `src/components/layout/Layout.tsx` — so change both together and keep them equal, otherwise content slides under the sidebar.
- The space between a project page's main photo and the first header below it comes from the `--photo-to-header-gap` token in `src/index.css`, applied by the `.photo-to-header-gap` class on the content section in `src/pages/ArtworkDetail.tsx`, so every project page's gap is tuned from that one value instead of per-page padding utilities.
- Project thumbnail and detail media share `ImageReveal`, which detects MP4 and WebM paths and renders them as muted looping inline video so data entries can switch media types without page-specific branches.
