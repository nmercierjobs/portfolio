# Standardize project cover images

## Changes
- Make every main image at the top of a project page use the same 4:3 frame.
- Fit the complete image inside that frame without cropping.
- Preserve the current image position and rounded corners.

## Verification
- Check all four project pages at desktop and phone widths.
- Confirm each frame is 4:3, equal-height at a given viewport, and shows the complete image.
